# Little Kitchen Atlas

An interactive recipe explorer for an HTML/CSS design activity.

**Live website:** https://pixel-kitchen-atlas.suyuw.chatgpt.site/

## Experience
Choose a highlighted country on the map, discover a dish with its local-language name and English translation, and flip its illustrated card to read the ingredients and steps.

## Files
- `index.html`: semantic structure and interactive SVG map outlines
- `style.css`: responsive layout, typography, colors and card flip animation
- `app.js`: country selection, data loading and flip controls
- `data.json`: eight simplified recipes and bilingual names
- `assets/`: original smooth vector food illustrations

## Run locally
Open this folder in VS Code and use Live Server on `index.html`. Use a server because recipe data is loaded with fetch.

## Design and technology
Soft cream and sage colors, rounded cards, smooth food illustrations and clear typographic hierarchy. HTML and CSS define the structure and visual design; a small JavaScript file implements navigation and flipping. AI assisted the implementation through iterative prompts and revisions.

## Credits
Map outlines: Natural Earth via datasets/geo-countries (https://github.com/datasets/geo-countries). Simplified culinary overview, not a boundary reference. Food illustrations are original SVG drawings. Recipes are simplified home-kitchen versions.
